# FRN Stock & Prices

Solución WordPress para publicar stock y precios B2B de FRN Atlántico sin reemplazar la portada actual.

## Alcance

- Landing de Pescado y Marisco.
- Landing de Carne.
- Importación de Excel desde el administrador de WordPress.
- Previsualización antes de publicar.
- CTA comercial por WhatsApp.
- Preparación para protección por usuario/contraseña, desactivada inicialmente.

El proyecto se integra como plugin para mantener los cambios aislados del tema y de las landings existentes.
