PROBLEMA CORREGIDO
------------------
Algunos visores mostraban pequeños artefactos o letras aparentemente
“borradas” en texto de 6-7 pt, especialmente con la marca de agua
transparente superpuesta.

El PDF original contiene el texto completo y las fuentes están embebidas.
La 1.1.18 refuerza la salida gráfica para que sea más estable entre visores.

CAMBIOS
-------
- Texto de tabla: 7,1 pt -> 7,6 pt.
- Encabezados: 6,2 pt -> 7 pt.
- Código con peso 600.
- Menos letter-spacing.
- Marca de agua: 300 pt -> 250 pt.
- Opacidad marca de agua: 5,5% -> 1,8%.
- Mantiene DejaVu Sans/Serif embebidas y sin font subsetting.

PRUEBA
------
1. Instalar v1.1.18 sustituyendo v1.1.17.
2. NO importar Excel.
3. NO crear una tarifa nueva.
4. Abrir la tarifa que ya corregiste.
5. Descargar otra vez el PDF.
6. Revisar especialmente:
   - CÓDIGO;
   - ESPAÑA;
   - nombres con Ñ/acentos;
   - códigos C00028/C00500/C00700;
   - texto sobre la zona de marca de agua.
