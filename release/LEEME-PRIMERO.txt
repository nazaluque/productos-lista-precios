CAMBIO PRINCIPAL
----------------
A partir de 1.0 los datos se cargan por separado:

1. STOCKS
   - export semanal de Odoo;
   - lo que no venga o venga con stock 0 queda destildado;
   - no modifica precios.

2. TARIFA DE PRECIOS
   - archivo comercial independiente;
   - puede guardarse con nombres distintos:
     General, Valdepeice, Madrid, HORECA, etc.;
   - no modifica el stock.

Al crear el PDF se combinan:
STOCK VIGENTE + TARIFA DE PRECIOS ELEGIDA.

PDF
---
- Nunca imprime 0,00 € como precio.
- Una línea destildada no sale.
- Descargar PDF/CSV guarda antes los cambios de la pantalla.
- Filas alternas claro/oscuro para facilitar lectura.
- La sección PRÓXIMOS INGRESOS aparece siempre.
- Si está vacía, muestra:
  "Actualmente no hay próximos ingresos informados."
- Los códigos XXX / XXXX / XXXXX... se consideran próximos ingresos.
- Carne y Pescado/Marisco generan PDFs separados.

INSTALACIÓN
-----------
En WordPress de frnatlantico.es:

1. Plugins > Añadir plugin > Subir plugin
2. Instalar:
   01-INSTALAR-FRN-STOCK-PRECIOS-v1.0.0.zip
3. Reemplazar la versión anterior.
4. FRN Home 1.1.0 puede quedarse instalado sin cambios.

FLUJO DE TRABAJO
----------------
LUNES / STOCK:
Odoo → Exportar stocks → Importar STOCKS → Previsualizar → Actualizar stock.

COMERCIAL / PRECIOS:
Excel de precios → Importar TARIFA → poner nombre → Previsualizar → Guardar tarifa.

SALIDA:
Crear PDF → elegir Carne o Pescado/Marisco → elegir tarifa de precios →
elegir General / Distribuidor / Disponibilidad → ajustar → Descargar PDF.

PRESets
-------
General:
precio + "Disponible"

Distribuidor:
precio + stock exacto

Disponibilidad:
sin precio + "Disponible"

Personalizado:
configuración manual.
