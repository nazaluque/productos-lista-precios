FRN · PAQUETE v0.9 · TARIFAS SEMANALES
=======================================

SOLO PARA
---------
frnatlantico.es

NO TOCAR
--------
frnatlantico.com

CAMBIOS 0.9
-----------
- Productos normales con stock 0 quedan destildados automáticamente.
- Al actualizar desde 0.8, también se destildan los productos existentes con stock 0.
- Los códigos XXX / XXXX / XXXXX... siguen como PRÓXIMOS INGRESOS aunque no tengan stock.
- Botones rápidos:
  - Tildar todos
  - Destildar todos
  - Solo con stock
  - Marcar todas como oferta
  - Quitar todas las ofertas
- Se crean dos tarifas independientes:
  - Tarifa Carne
  - Tarifa Pescado / Marisco
- Presets de salida:
  - General = precio + Disponible
  - Distribuidor = precio + stock exacto
  - Disponibilidad = sin precio + Disponible
  - Personalizado
- Al desactivar Mostrar stock se destildan los "Ver stock" de todas las líneas.
- Al desactivar Mostrar precio se destildan los "Ver precio" de todas las líneas.
- El PDF elimina por completo la columna Stock o Precio cuando globalmente están ocultas.
- El selector Estado/Borrador/Final desaparece de la interfaz.
- En la tarifa editable hay una sola fila de acciones al final:
  Guardar tarifa · Descargar PDF · Descargar CSV.

INSTALACIÓN
-----------
1. WordPress de frnatlantico.es
2. Plugins > Añadir plugin > Subir plugin
3. Instalar:
   01-INSTALAR-FRN-STOCK-PRECIOS-v0.9.0.zip
4. Reemplazar la versión anterior.
5. FRN Home 1.1.0 puede quedarse como está.

PRÓXIMOS INGRESOS
-----------------
Los códigos formados solo por tres o más X se separan del stock actual:
XXX, XXXX, XXXXX...

No se exige stock positivo para incluirlos.

NOTA
----
Cuando tengamos el export real definitivo de Odoo se afina únicamente el parser.
La aplicación y los PDF no necesitan rediseñarse.
