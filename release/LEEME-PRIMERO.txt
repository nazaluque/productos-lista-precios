FRN · PAQUETE v0.8 · HERRAMIENTA 100% FRONTEND
================================================

IMPORTANTE
----------
Este paquete es SOLO para frnatlantico.es.
NO instalar ni modificar frnatlantico.com.

QUÉ CAMBIA EN 0.8
-----------------
- El usuario FRN Comercial NO entra al panel wp-admin.
- Después del login trabaja siempre en el frontend:
  https://frnatlantico.es/stock/
- Solo hay dos funciones principales:
  1. Importar Excel semanal
  2. Crear PDF
- Se eliminan las vistas de catálogo Pescado/Marisco y Carne.
- Los enlaces antiguos /stock/pescado-marisco/ y /stock/carne/ vuelven a /stock/.
- El Excel importado se muestra como una tabla editable.
- Se puede modificar precio, stock, nombre, marca, oferta y si una referencia se usa.
- Los códigos formados únicamente por 3 o más X (XXX, XXXX, XXXXX...) se clasifican automáticamente como PRÓXIMOS INGRESOS.
- Se admiten varios productos con código XXX.
- Próximos ingresos aparecen en una sección separada al final de la tabla y del PDF.
- Las tarifas se guardan por semana y conservan el precio/stock original.

INSTALACIÓN
-----------
En WordPress de frnatlantico.es:

1. Plugins > Añadir plugin > Subir plugin
2. Instalar 01-INSTALAR-FRN-STOCK-PRECIOS-v0.8.0.zip
3. Reemplazar la versión anterior.
4. Mantener FRN Home 1.1.0 si ya está instalado.

USUARIO INTERNO
---------------
Usuarios > Añadir nuevo

Crear el usuario y contraseña deseados.
Rol:
FRN Comercial

Ese usuario:
- puede entrar en /stock/;
- puede importar Excel;
- puede editar los datos comerciales;
- puede generar tarifas;
- NO puede navegar por wp-admin.

FLUJO DEL LUNES
---------------
1. Entrar desde "Ver productos, stock y precios".
2. Usuario + contraseña.
3. Importar uno o varios Excel.
4. Previsualizar.
5. Publicar.
6. Revisar la tabla:
   - Productos
   - Próximos ingresos
7. Cambiar precio/stock/oferta si hace falta.
8. Ir a "Crear PDF".
9. Crear tarifa.
10. Ajustar qué se imprime.
11. Descargar PDF.

EXCEL DE ODOO
-------------
La versión 0.8 reconoce:
- el formato maestro CARNE_IMPORT / PESCADO_IMPORT;
- Excel separados cuyo nombre o pestaña identifique Carne o Pescado/Marisco;
- códigos C... y P... como ayuda para detectar la categoría.

Cuando se entregue el Excel real exportado por Odoo se termina de afinar el parser
sin cambiar la interfaz ni el sistema de tarifas.
