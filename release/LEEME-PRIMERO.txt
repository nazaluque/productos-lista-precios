NOVEDAD PRINCIPAL
-----------------
Cada Excel indica explícitamente qué se quiere actualizar:
- Stock
- Precio
- Coste promedio
- Categorías / orden desde hojas Resumen

Un campo NO marcado nunca se modifica.
Una columna ausente o una celda vacía no borra precios/costes existentes.

EXCEL 28-09-2026
----------------
La hoja maestra de datos alimenta stock/precio/coste.
Las hojas Resumen Carne y Resumen Pescado se utilizan como estructura comercial:
- categorías;
- orden de categorías;
- orden de productos dentro de cada categoría.

Los productos sin categoría de Resumen se muestran en la previsualización antes de publicar.

IDIOMAS
-------
El maestro conserva el nombre original y añade:
- Español Argentina / original
- Español España
- Português Portugal
- English

Al crear una tarifa se selecciona el mercado:
- España
- Portugal
- Internacional

Para Carne:
España = Argentina + España
Portugal = Argentina + Português
Internacional = Argentina + English

Para Pescado / Marisco:
España = Español
Portugal = Español + Português
Internacional = Español + English

PDF / CSV
---------
PDF A4 apaisado.
Productos agrupados por categoría comercial con bandas de color.
La cabecera usa la foto configurada en Diseño PDF con recorte proporcional tipo cover: ocupa el ancho sin deformar la imagen.
Se mantienen:
- badge OFERTA;
- stock exacto / redondeado / Disponible;
- precio / Consultar precio;
- coste solo con permiso;
- próximos ingresos;
- marca de agua;
- footer y datos FRN.

INSTALACIÓN
-----------
1. WordPress > Plugins > Añadir plugin > Subir plugin.
2. Instalar 01-INSTALAR-FRN-STOCK-PRECIOS-v1.1.14.zip.
3. Sustituir la versión anterior.
4. Entrar en /stock/ y confirmar v1.1.14.
5. La primera carga ejecuta la migración de tablas automáticamente.

PRUEBA RECOMENDADA
------------------
Con I 28-09-2026.xlsx:
- marcar Stock;
- marcar Categorías / orden;
- NO marcar Precio;
- NO marcar Coste.

La previsualización debe mostrar que precio y coste NO SE TOCAN.
