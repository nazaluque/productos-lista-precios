CAMBIOS SOBRE 1.1.14
--------------------
1. Flujo de importación:
   Seleccionar → Analizar → Publicar.
   Analizar NO modifica la base.

2. Después de analizar:
   - se muestra el nombre del Excel analizado;
   - desaparece el mensaje confuso de “ningún archivo seleccionado”;
   - la pantalla indica que todavía NO se publicó.

3. Protección de datos:
   - Stock, Precio, Coste y Categorías/orden siguen siendo independientes.
   - Solo se modifica lo marcado.

4. Unidades:
   - La previsualización separa kg de unidades.
   - No mezcla ambos valores en un único total.

5. Categorías:
   - Las referencias fuera de las hojas Resumen aparecen como SIN CATEGORÍA.
   - En el PDF reciben una banda neutra propia.

6. PDF:
   - A4 apaisado.
   - Cabecera fotográfica corregida.
   - La foto se inserta como imagen real para Dompdf; no como background data URI.
   - La fotografía se recorta dentro de la cabecera y no se estira.
   - El ajuste estético fino de encuadre podrá hacerse después de revisar un PDF real.
