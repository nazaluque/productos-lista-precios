FRN Stock & Prices · v1.3.3
REPARACIÓN DEL EDITOR DE PEDIDOS

SOLO PARA frnatlantico.es
NO INSTALAR EN frnatlantico.com

PROBLEMA CORREGIDO
------------------
El editor de pedidos quedaba sin respuesta:
- al seleccionar un cliente no se rellenaban sus datos;
- “Añadir producto” no hacía nada;
- las líneas de producto no se inicializaban.

CAUSA
-----
assets/app.js contenía un error real de sintaxis:
se había insertado un \n literal dentro de una sentencia JavaScript al
modificar la lógica de pallets.

Ese único error impedía ejecutar todo el bloque JavaScript de Pedidos.

SEGURIDAD DE DATOS
------------------
Esta versión NO borra ni reinicia:
- clientes;
- pedidos;
- productos;
- precios;
- stock;
- tarifas;
- traducciones;
- categorías.

INSTALACIÓN
-----------
1. WordPress > Plugins > Añadir plugin > Subir plugin.
2. Instalar FRN-STOCK-PRECIOS-v1.3.3 sustituyendo la versión anterior.
3. NO borrar datos ni reimportar Excel.
4. Abrir /stock/?tab=pedido&type=pedido
5. Seleccionar un cliente y comprobar que se completan sus datos.
6. Pulsar “+ Añadir producto” y comprobar que aparece una nueva línea.

VALIDACIÓN
----------
GitHub Actions incluye ahora:
- PHP syntax check;
- JavaScript syntax check con node --check;
- contrato de versión.
