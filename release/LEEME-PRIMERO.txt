FRN · PAQUETE v1.1.4 · MAESTRO SEMANAL UNIFICADO
================================================

SOLO PARA frnatlantico.es
NO TOCAR frnatlantico.com

FLUJO
-----
1. Entrar en /stock/acceso/
2. Importar el Excel semanal de Odoo.
3. Revisar stock y precios comerciales.
4. Guardar.
5. Crear PDF/CSV de Carne o Pescado / Marisco.

EXCEL SEMANAL
-------------
La aplicación admite XLSX/XLS, una o varias hojas y uno o varios archivos.

Cabeceras soportadas:
- Nombre del producto
- Referencia Interna
- Marca
- Modelo
- Categoria del producto
- Precio de venta
- Costo / Coste / Costo promedio / Coste promedio
- Stock
- Unidad / Unidad de medida

REGLA DE STOCK
--------------
Solo se incorporan a la disponibilidad actual productos con stock > 0.
Los productos históricos que ya existían no se borran: quedan con stock 0 y fuera de la selección semanal.

PRECIOS
-------
El archivo puede traer Precio de venta como precio origen.
El precio comercial se puede editar dentro de /stock/ y se conserva entre semanas.
La importación no pisa un precio comercial ya ajustado.

COSTE PROMEDIO
--------------
Se guarda desde Odoo, pero solo es visible y exportable para usuarios con permiso frn_view_cost.
Un usuario sin ese permiso no ve el coste ni en pantalla ni en PDF/CSV.

ROLES
-----
FRN Administrador:
- stock
- precios
- coste
- exportación
- usuarios

FRN Stock:
- importar/editar stock
- exportar
- sin coste

FRN Director Comercial:
- editar precios
- ver/exportar coste
- exportar

FRN Comercial:
- consultar/exportar
- sin coste

FRN Consulta:
- consultar/exportar
- sin edición
- sin coste

USUARIOS
--------
Los crea un FRN Administrador desde la pestaña Usuarios de /stock/.
Todos acceden por /stock/acceso/.
Los perfiles FRN no necesitan wp-admin.

PDF / CSV
---------
Carne y Pescado / Marisco se generan siempre por separado.
Opciones:
- precio
- stock exacto
- stock redondeado
- Disponible
- coste promedio (solo con permiso)

Línea destildada: nunca sale.
Precio 0 o vacío: Consultar precio.
Coste 0: vacío.
Próximos ingresos aparece siempre.

VERSIÓN
-------
La versión instalada se muestra dentro de /stock/ en cabecera, pantalla y pie.
Versión de este paquete: 1.1.4
