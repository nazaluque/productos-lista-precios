FORMATO SEMANAL
---------------
La versión 1.1.16 está preparada para el formato de una sola hoja usado en:
stock naza.xlsx

Columnas reconocidas:
- Nombre del producto
- Marca
- Referencia interna
- Precio de venta
- Coste
- Categoria de producto
- Pronosticado
- Unidades

IMPORTACIÓN POR DEFECTO
-----------------------
[✓] Stock
[✓] Precio
[✓] Coste promedio
[ ] Categorías / orden comercial

Las categorías comerciales y las traducciones quedan guardadas en la plataforma.
No se sobrescriben semanalmente salvo que se marque expresamente Categorías / orden.

PROTECCIONES
------------
- Stock negativo: se avisa y se publica como 0 / no disponible.
- Precio 0: se avisa y el PDF muestra “Consultar precio”.
- Precio de venta inferior al coste: se avisa, pero no bloquea la importación.
- Las traducciones revisadas manualmente no se pisan en futuras importaciones.

TRADUCCIONES
------------
Nueva pestaña TRADUCCIONES.

Permite editar por producto:
- Grupo comercial
- Español España
- Português Portugal
- English
- Revisada Sí/No

El nombre original de Odoo no se modifica desde esta pantalla.

Filtros:
- búsqueda por código/producto/grupo;
- Carne / Pescado-Marisco;
- Solo pendientes.

NOMENCLATURA CARNE
------------------
Se corrigen automáticamente las traducciones no revisadas:
- TAPA DE CUADRIL -> PICAÑA
- CORAZON DE CUADRIL -> CADERA / CROCA

Las traducciones ya marcadas como revisadas se respetan.

PRODUCTOS NUEVOS
----------------
Si aparece un código nuevo:
- se importa stock/precio/coste;
- recibe una sugerencia inicial de grupo comercial;
- queda disponible en Traducciones para revisión manual.

INSTALACIÓN
-----------
1. WordPress > Plugins > Añadir plugin > Subir plugin.
2. Instalar 01-INSTALAR-FRN-STOCK-PRECIOS-v1.1.16.zip.
3. Sustituir la versión anterior.
4. Entrar en /stock/ y confirmar v1.1.16.
5. La primera carga ejecuta automáticamente la migración.

PRUEBA RECOMENDADA
------------------
Subir stock naza.xlsx con:
[✓] Stock
[✓] Precio
[✓] Coste promedio
[ ] Categorías / orden comercial

Primero pulsar ANALIZAR.
Revisar alertas.
Después PUBLICAR.
